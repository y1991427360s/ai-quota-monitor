登录 / 绑定 ChatGPT Plus 会员账号
  1. 点击下方「打开 OpenAI 官方登录授权」，在官方页面登录你的 Plus 会员；
  2. 同意 Codex CLI 访问授权；
  3. 浏览器将跳转到一个无法连接的 http://localhost:1455/auth/callback?code=... 页面；
  4. 复制浏览器地址栏的完整网址，粘贴到下方输入框，点击绑定即可！
可直接粘贴以下任意一种凭据：
  1. 浏览器登录 chatgpt.com 后访问 chatgpt.com/api/auth/session 的全文 JSON；
  2. 或 DevTools / Cookie 中的 accessToken 字符串。
添加 Google 账号授权
  1. 点击下方「打开谷歌授权页」登录你的 Google AI 账号；
  2. 在 Google 页面完成权限勾选并点击继续；
  3. 页面将跳转到一个无法连接的 http://127.0.0.1:8085/callback?code=... 页面；
  4. 复制浏览器地址栏的完整网址，粘贴到下方输入框，点击完成绑定。
